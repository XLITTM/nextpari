# Nextpari Exact Glossy Icon Pack v2

Это финальный пакет, вырезанный непосредственно из утверждённого глянцевого борда Nextpari.

## Что внутри
- `dark/` — точные иконки из борда для тёмной темы.
- `light/` — те же формы; цветные/спортивные иконки сохранены, нейтральные адаптированы в slate для светлой темы.
- `design/NEXTPARI_ICON_SYSTEM_GOLDEN_REFERENCE.png` — эталон.
- `manifest.json` — точное назначение, группа и рекомендованный размер каждой иконки.
- `CURSOR_PROMPT_FINAL.txt` — готовый промпт Cursor.

## Ключевое правило
Cursor НЕ рисует и НЕ подбирает иконки.
Он подключает готовые PNG из этого ZIP.

Спортивные иконки сохраняют цвет и глянцевый вид из утверждённой картинки.
Нижняя навигация, верхние вкладки, меню и служебные иконки следуют самому борду,
а не предыдущей rainbow/Phosphor-интерпретации.

Legacy/Premium rollback сохраняется.
